## Why

The 2.4 backport (register M-21) carries #19440 (the scratch uberblocks of a RAID-Z expansion written through `VERIFY0()` instead of `ASSERT0()`, so that release builds write them), #19550 and the two ZTS helpers they need, then the port of our master fix `0a4bf7d5243` ("raidz: pause the expansion when a scratch uberblock is not written"): those uberblocks go out with `ZIO_FLAG_CANFAIL` through `raidz_reflow_scratch_ub_sync()`, and when no disk takes one, the expansion pauses instead of panicking (`VERIFY0()` in `txg_sync` on release, `zio_done()` on debug). Version 4 is rebuilt on tonyhutter's `zfs-2.4.5` tag commit `b0e64ccd5bf` ("Tag zfs-2.4.5", the 2.4.5 candidate), which already carries #19590: `8ab453596d1` (upstream `5e672734420`, "raidz: fix write ASSERTs for scratch area columns") and `9649963215a` (the import path's error exit). So the port now also carries master's import-path hunk: `vdev_raidz_reflow_copy_scratch()` pauses instead of `VERIFY0()` when its uberblock is not written (debug log `reflow recovery: error ... writing uberblock`; no test reaches it).

The case-2 check. TASK-1120-M21 ran the same test on the port's first base (`zfs-2.4.5-staging`, without `5e672734420`): release passed 3 of 3, but the first debug run panicked in its second case, after `reflow: error 5 writing uberblock (SCRATCH_INVALID_SYNCED)` and during the `zpool clear` that resumes the pool: `VERIFY3U(rc->rc_offset + rc->rc_size, <, cvd->vdev_psize - VDEV_LABEL_END_SIZE) failed (18446744073705882112 < 267911168)`, `PANIC at vdev_raidz.c:2455:vdev_raidz_io_start_write()` in `z_wr_iss`. While the expansion is paused with the scratch area in use, a write to the first 17.5 MiB of the vdev is mapped into the scratch area with a column offset that wraps below zero on purpose (`zio_vdev_child_io()` adds the front labels back), and the debug-only bounds assertions compared the wrapped value. `5e672734420` fixes those assertions; TASK-1120-M21B showed it on the kernel: a kprobe counter on `zio_vdev_child_io()` counts the child writes mapped to the scratch area (`scratch`), which happened in 2 of 5 fixed runs and 1 of 5 master runs, all passing, while the unfixed kit panicked again. Whether a run hits that window depends on where the sync thread allocates in the txg of the failure. Here the same counter runs on the debug kit: a debug run with `scratch` above 0 and no assertion is the check that v4's base closes that panic; 10 runs, then 10 more if none of the first 10 hit the window.

The sequence codes the debug log's `reflow:` lines: W `wrote ... to scratch area`, E1 and E2 `error ... writing uberblock (SCRATCH_VALID)` and `(SCRATCH_INVALID_SYNCED)`, U1 and U0 `uberblock updated (txg ..., SCRATCH_VALID,` and `SCRATCH_NOT_IN_USE,`, O `overwrote ... to real location`, X any other `reflow:` line. SEQ-OK is the designed `W E1 W U1 O U0 W U1 O E2 O U0`: case 1 writes the scratch area, fails its uberblock, and after the clear redoes it all; case 2 fails its second uberblock, and after the clear overwrites again from the scratch area (no new W). `notes` counts the test's two `uberblock write failing for` NOTE lines, `suspended` and `resumed` the kernel's `Pool 'testpool' has encountered an uncorrectable I/O failure and has been suspended` and `Pool 'testpool' was suspended and is being resumed` lines, `bad` the `VERIFY|ASSERT|PANIC|BUG|Oops|Call Trace|blocked for more than` lines; `dmesg=cleared` says a failure callback emptied the ring. `scratch`, `w`, `r` and `area` count the kprobe hits of the run (`-` without kprobes): `scratch` the child i/o mapped to the scratch area, of which `w` writes and `r` reads, and `area` every child i/o below offset 0 (expected 20 plus `scratch`: the scratch phase writes the scratch area of the 5 children three times and reads it once). A `scratch` above 0 is the window of TASK-1120-M21's debug panic.

```sh
#!/bin/sh
# TASK-1121-B24 runs of the test, as the login user: runs.sh <tag> <runs> <tree>
PATH=$PATH:/usr/sbin:/sbin
D=/var/tmp/task-1121-b24
L=/var/log/task-1121-b24
T=raidz_expand_scratch_uberblock
E=/sys/kernel/tracing
tag=$1
runs=$2
Z=$D/$3
out=$L/runs-$tag.txt
want="W E1 W U1 O U0 W U1 O E2 O U0"
susp="Pool 'testpool' has encountered an uncorrectable I/O failure and has been suspended"
resm="Pool 'testpool' was suspended and is being resumed"
cd $Z || exit 1
sv=$(modinfo -F srcversion $Z/module/zfs.ko)
kp=no
sudo -n test -e $E/events/b24/scratch/enable && kp=yes
echo "START $tag $(date -u +%FT%TZ) tree=$3 srcversion=$sv kprobe=$kp" >> $out
n=1
while [ $n -le $runs ]; do
    loaded=$(cat /sys/module/zfs/srcversion 2>&1)
    pools=$(timeout 30 sudo -n $Z/zpool list -H -o name 2>&1)
    inj=$(timeout 30 sudo -n $Z/zinject 2>&1 | head -n 1)
    left=$(ls -d /var/tmp/file-vdev* /var/tmp/dev-* 2>/dev/null)
    if [ "$loaded" != "$sv" ] || [ -n "$pools" ] ||
        [ "$inj" != "No handlers registered." ] || [ -n "$left" ] ||
        [ -s /etc/zfs/zpool.cache ]; then
        echo "STOP before $tag-$n: loaded=[$loaded] pools=[$pools]" \
            "zinject=[$inj] left=[$left]" \
            "cache=[$(ls -l /etc/zfs/zpool.cache 2>&1)]" >> $out
        exit 1
    fi
    [ $kp = yes ] && sudo -n sh -c "echo > $E/trace"
    # The debug log counts whole seconds: keep the last run out of t0's.
    sleep 2
    n0=$(sudo -n dmesg | wc -l)
    t0=$(date +%s)
    sudo -n -u zts ./scripts/zfs-tests.sh -vKO -t $T \
        > $L/zts-$tag-$n.log 2>&1 < /dev/null
    rc=$?
    secs=$(($(date +%s) - t0))
    # A failing test's callbacks run "dmesg -c": then count the whole ring.
    ring=kept
    if [ "$(sudo -n dmesg | wc -l)" -lt "$n0" ]; then
        ring=cleared
        n0=0
    fi
    sudo -n dmesg | tail -n +$((n0 + 1)) > $L/dmesg-$tag-$n.txt
    sudo -n cat /proc/spl/kstat/zfs/dbgmsg |
        awk -v t=$t0 '$1 >= t && /: reflow: /' > $L/dbg-$tag-$n.txt
    seq=$(awk '
        /reflow: wrote [0-9]+ bytes/ { s = s " W"; next }
        /writing uberblock [(]SCRATCH_VALID[)]/ { s = s " E1"; next }
        /writing uberblock [(]SCRATCH_INVALID_SYNCED[)]/ { s = s " E2"; next }
        /uberblock updated [(]txg [0-9]+, SCRATCH_VALID,/ { s = s " U1"; next }
        /uberblock updated [(]txg [0-9]+, SCRATCH_NOT_IN_USE,/ { s = s " U0"; next }
        /reflow: overwrote [0-9]+ bytes/ { s = s " O"; next }
        { s = s " X" }
        END { print substr(s, 2) }' $L/dbg-$tag-$n.txt)
    if [ "$seq" = "$want" ]; then
        sq=SEQ-OK
    else
        sq=SEQ-OTHER
    fi
    st=-
    sw=-
    sr=-
    sa=-
    if [ $kp = yes ]; then
        sudo -n cat $E/trace > $L/kp-$tag-$n.txt
        st=$(grep -c ' scratch: ' $L/kp-$tag-$n.txt)
        sw=$(grep -c ' scratch: .* type=2$' $L/kp-$tag-$n.txt)
        sr=$(grep -c ' scratch: .* type=1$' $L/kp-$tag-$n.txt)
        sa=$(grep -c ' area: ' $L/kp-$tag-$n.txt)
    fi
    R=$(awk '/^Log directory/ { print $3 }' $L/zts-$tag-$n.log)
    res=$(sed 's/\x1b\[[0-9;]*m//g' $L/zts-$tag-$n.log |
        grep -oE "/$T(\.ksh)? .*\[[A-Z]+\]" |
        grep -oE '\[[0-9:]+\] \[[A-Z]+\]$')
    notes=$(grep -c 'uberblock write failing for' "$R/log" 2>/dev/null)
    s=$(grep -c "$susp" $L/dmesg-$tag-$n.txt)
    r=$(grep -c "$resm" $L/dmesg-$tag-$n.txt)
    bad=$(grep -c -E 'VERIFY|ASSERT|PANIC|BUG|Oops|Call Trace|blocked for more than' \
        $L/dmesg-$tag-$n.txt)
    echo "$tag-$n rc=$rc result=$res secs=$secs notes=$notes $sq [$seq]" \
        "suspended=$s resumed=$r bad=$bad scratch=$st w=$sw r=$sr" \
        "area=$sa dmesg=$ring dir=$R" >> $out
    n=$((n + 1))
done
echo "DONE $tag $(date -u +%FT%TZ)" >> $out
```

`kp.sh on|off` runs as root. `on` adds the two kprobe events `b24/scratch` and `b24/area` on `zio_vdev_child_io()` with their filters, enables them, empties the trace buffer and prints `KPROBE-ON` with the filters and the two event definitions; on any error it removes what it added and exits 1. `off` disables and removes them and prints `KPROBE-OFF 0`.

```sh
#!/bin/sh
# TASK-1121-B24 counters of child i/o below offset 0, as root: kp.sh on|off
# area: every such i/o; scratch: those smaller than the scratch area, which
# are blocks that vdev_raidz_map_alloc_expanded() mapped there.
E=/sys/kernel/tracing
off() {
    echo 0 > $E/events/b24/enable 2>/dev/null
    echo '-:b24/scratch' >> $E/kprobe_events 2>/dev/null
    echo '-:b24/area' >> $E/kprobe_events 2>/dev/null
    echo "KPROBE-OFF $(grep -c b24 $E/kprobe_events)"
}
case $1 in
on)
    for p in scratch area; do
        echo "p:b24/$p zio_vdev_child_io off=\$arg4:u64 size=\$arg6:u64 type=\$arg7:s32" \
            >> $E/kprobe_events || { off; exit 1; }
    done
    echo 'off >= 9223372036854775808 && size < 3670016' \
        > $E/events/b24/scratch/filter || { off; exit 1; }
    echo 'off >= 9223372036854775808' > $E/events/b24/area/filter ||
        { off; exit 1; }
    echo 1 > $E/events/b24/enable || { off; exit 1; }
    echo > $E/trace
    echo "KPROBE-ON scratch=[$(cat $E/events/b24/scratch/filter)]" \
        "area=[$(cat $E/events/b24/area/filter)]"
    grep b24 $E/kprobe_events
    ;;
off)
    off
    ;;
*)
    exit 2
    ;;
esac
```

`cap.sh <tag> <console log>` runs as root and runs no `zpool` or `zfs` command. It saves the kernel ring (`$L/dmesg-<tag>.txt`), this boot's kernel log from the journal (`$L/journal-<tag>.txt`) and the debug log (`$L/dbgmsg-<tag>.txt`), and writes to `$L/cap-<tag>.txt`: the first `VERIFY`, `ASSERT` or `PANIC` line of this boot with the 40 lines after it (from the journal, or the ring when the journal has none), the hung-task reports, the threads in state D and the zfs threads with their wait channels, the kernel stack of every thread in state D, of `txg_sync` and `raidz_expand`, and of any thread in `spl_panic`, the last 40 lines of the console log, and the debug log's reflow and `command:` lines and last 20 lines. Then `sync -f`.

```sh
#!/bin/sh
# TASK-1121-B24 capture of a stuck module, as root: cap.sh <tag> <console log>
# Runs no zpool or zfs command: they would block.
L=/var/log/task-1121-b24
tag=$1
log=$2
out=$L/cap-$tag.txt
dmesg > $L/dmesg-$tag.txt 2>&1
journalctl -k -b --no-pager > $L/journal-$tag.txt 2>&1
# The journal keeps what a test's "dmesg -c" removes from the ring.
k=$L/journal-$tag.txt
grep -a -q -E 'VERIFY|ASSERT|PANIC' $k || k=$L/dmesg-$tag.txt
{
    echo "CAPTURE $tag $(date -u +%FT%TZ), up since $(uptime -s)"
    echo "== first VERIFY/ASSERT/PANIC of this boot, and 40 lines after it ($k)"
    grep -a -m 1 -A 40 -E 'VERIFY|ASSERT|PANIC' $k
    echo "== hung-task reports"
    grep -a 'blocked for more than' $k
    echo "== threads in D state, and the zfs threads"
    ps -eLo pid,tid,stat,comm,wchan:32 |
        awk 'NR == 1 || $3 ~ /^D/ || $4 ~ /^(txg_|z_null|z_wr_iss|raidz|zpool|zinject|ksh)/'
    for t in /proc/[0-9]*/task/[0-9]*; do
        st=$(cat $t/stack 2>/dev/null) || continue
        c=$(cat $t/comm 2>/dev/null)
        s=$(sed 's/.*) //' $t/stat 2>/dev/null | cut -d ' ' -f 1)
        case "$s $c $st" in
        D\ *|*\ txg_sync\ *|*\ raidz_expand\ *|*spl_panic*)
            echo "== stack of ${t#/proc/} ($c, state $s)"
            echo "$st"
            ;;
        esac
    done
    echo "== console log, last 40 lines"
    tail -n 40 "$log"
    echo "== debug log: reflow and command lines, then its last 20 lines"
    timeout 20 cat /proc/spl/kstat/zfs/dbgmsg > $L/dbgmsg-$tag.txt 2>&1
    grep -a -E ': reflow|command: ' $L/dbgmsg-$tag.txt | tail -n 40
    tail -n 20 $L/dbgmsg-$tag.txt
} > $out 2>&1
sync -f $out $k $L/dbgmsg-$tag.txt
echo "CAPTURED $tag: $out"
```
